Questions

Do I need an account?
No. You can explore every page without signing up. An account is only needed when you download a game. Use the Sign up button at the top of any page.
How do I install a game on Android?
  1. Open the Games page and tap Install on the game you want.
  2. Choose Android and follow the link.
  3. Tap Install and wait for the download to finish.
  4. If asked, allow installs from this source, then open the game.
How do I install a game on iPhone?
  1. Open the Games page and tap Install on the game you want.
  2. Choose iPhone and follow the link.
  3. Tap Get and confirm with Face ID, Touch ID or your passcode.
  4. Open the game from your home screen.
How do I install a game on Windows?
  1. Open the Games page and click Install on the game you want.
  2. Choose Windows and wait for the installer or zip file to download.
  3. Open the file. If it is a zip, extract it first, then run the installer.
  4. If Windows SmartScreen warns you, check the file came from this site, then choose More info and Run anyway.
  5. Start the game from the Start menu or the desktop shortcut.
The Install button says the link is not ready
That game has no download link yet for your device. It will be enabled once it is released. Check back soon.
