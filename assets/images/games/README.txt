Put your custom game icons here.

Name each file after the game, lowercase, words joined by hyphens, .png:

  Pixel Drift    -> pixel-drift.png
  Block Garden   -> block-garden.png
  Cave Runner    -> cave-runner.png
  Tiny Kingdom   -> tiny-kingdom.png
  Star Sorter    -> star-sorter.png
  Moss & Mortar  -> moss-mortar.png

Use square images (e.g. 256x256). A game with no image here shows the
default pixel icon. To use another file name or format (jpg, webp, svg),
set img:"assets/images/games/yourfile.jpg" in js/games-data.js.
