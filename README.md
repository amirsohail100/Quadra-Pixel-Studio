## 📖 Overview

**Quadra Pixel** is a custom-built digital game storefront and community gaming hub inspired by **itch.io** and the **Microsoft Store**. Engineered as a zero-build static multi-page web application with Firebase integration, it serves as the official distribution platform for original games built by me, alongside community-submitted titles and Roblox experiences.

Currently deployed and live on a **monolithic architecture**, Quadra Pixel acts as the dedicated gaming and interactive entertainment hub of **Quadra**, my individual tech brand encompassing an entire ecosystem of custom software, developer tools, AI architectures, and web applications.

---

## 🌟 Core Vision & Purpose

- **Indie & Original Game Storefront:** Built to showcase and distribute my own custom games across Android, iOS, Windows, and Roblox without relying on restrictive third-party publishing bottlenecks.
- **Community-Driven Gaming Hub:** Empowers visiting developers and creators to upload their own games or link Roblox experiences with built-in moderation and approval workflows.
- **Zero-Friction Player Experience:** Designed with instant local demo mode fallback, multi-theme support (Dark/Light/System), personal game libraries, and streamlined multi-OS installation flows.

## 🏗️ System Architecture & Deployment Roadmap

### Current Phase: Monolithic Architecture

- **Rapid Iteration & Deployment:** Quadra Pixel is currently deployed on a monolithic static + Firebase architecture to prioritize fast UI updates, instant demo-mode testing, and direct game distribution.
- **Access Note:** Because routing and domain endpoints will evolve during upcoming infrastructure upgrades, permanent standalone URLs are intentionally kept off static posts. You can always access the live ecosystem via my [GitHub Profile](https://github.com/amirsohail100).

### Next Phase: Distributed Architecture

- **Microservices & Scalable Backend Migration:** Separating authentication, game asset CDN delivery, payment gateways, community moderation queues, and player libraries into independent distributed services.
- **Official Public Releases:** Once the transition to a distributed architecture is complete, official standalone domains and public APIs will be rolled out across Quadra Pixel and all other Quadra products.

## 🛠️ Tech Stack & Engineering Foundation

- **Frontend & UI:** HTML5, CSS3 (Custom CSS Variables, Dark/Light/System Themes), Vanilla JavaScript (ES6+), Responsive Multi-Page Architecture
- **Backend, Auth & Cloud:** Firebase Authentication, Cloud Firestore, Firebase Storage, LocalStorage Fallback Engine
- **Supported Game Platforms:** Android, iOS (iPhone), Windows, Roblox Web Integration
- **Game Dev & Asset Tooling:** Unity, Godot, Blender, Substance 3D Painter, C/C++, GDScript, Git, Git LFS
